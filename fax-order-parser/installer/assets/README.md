Place a 256×256 ICO file named `fax-parser.ico` here before running build-installer.ps1.

The icon is used for:
- The InnoSetup installer wizard
- The Start Menu and desktop shortcuts
- The app-icon.ico displayed in Programs & Features

You can create or convert an icon at https://convertio.co/png-ico/
or use any .ico from the assets/ folders in the other sub-projects as a placeholder.
